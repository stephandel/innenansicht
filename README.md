# Innenansicht

Eine Web-App für eine wöchentliche Sitzung mit sich selbst, 20 bis 30 Minuten, geführt durch systemische Werkzeuge: Skalierung mit Verlauf, Ausnahme- und zirkuläre Fragen, Inneres Team, Ressourcen-Inventur. Drei Bereiche wachsen aus den Sitzungen: Klarheit, Inneres Team, Verlauf.

- Läuft im Browser, lässt sich auf dem iPhone auf den Home-Bildschirm legen.
- Alle Daten bleiben auf dem Gerät. Kein Konto, kein Server, keine Anfrage nach außen.
- Sicherungsdatei zum Mitnehmen auf ein anderes Gerät.
- Keine Diagnosen, keine Bewertungen, keine Erinnerungen mit Druck.

`fragebogen/` enthält den Klärungs-Fragebogen, mit dem die Anforderungen gesammelt wurden.

Die App ist kein Ersatz für ärztliche Hilfe. In einer akuten Krise: Telefonseelsorge 0800 111 0 111, kostenlos, rund um die Uhr.
